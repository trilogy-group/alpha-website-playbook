# Pre-Announcement Campus Requirements

State: Pre-Announcement, as decided by HubSpot Programs.

## Public behavior

- No public campus WordPress page is required.
- A draft may exist for internal preparation, but it remains unpublished, noindex, absent from sitemaps, Markdown output, and LLM exports.
- The homepage and Locations map may show one approved pin for the exact HubSpot Program.
- The pin routes to a verified campus-specific Community destination using `https://www.community.alpha.school/?campus=<slug>`.
- The Community slug comes from an exact HubSpot Program ID join to a visible Community program record. It is never derived from the campus name.
- Public map identity, location, coordinates, and lifecycle match HubSpot and approved Operations data.
- No Apply, booking, packet, event, tuition, grade, opening-date, or staffing claim is published without an approved source and launch-stage rule.

## Internal draft

Draft preparation requires an explicit draft-only APEX ticket and exact object ID. Review links must not be presented as public completion. Forms, webhooks, indexing, analytics, and other external side effects are isolated during review.

## Transition to Announced

Before publishing a campus page, confirm:

- HubSpot lifecycle and Program identity
- Named launch date or approved wording
- Canonical slug and WordPress object
- Required source fields
- Approved page template and media
- CTA and application routing
- Community and map behavior
- Events label if used
- SEO, schema, sitemap, Markdown, and LLM-export policy
- Named owners and public verification plan

Publication is a coordinated launch checkpoint, not a status toggle performed from a generic website ticket.
