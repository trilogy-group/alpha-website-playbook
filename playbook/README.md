# Playbook (human-readable requirements)

- `00-how-to-use.md`: the operational entry point for a fresh agent or person.
- `campus-page/page-model.md`: the campus page template as it exists on the live site (M1).
- `site/site-rules.md`: site-wide rules with sources and enforcing checks.
- `site/mackenzie-style-choices.md`: MacKenzie Price's word-level style choices (the brand copy quiz sheet Haven Mass shared), with Test2Pass renamed to AlphaTest. Read before writing any page copy, team bio, FAQ, or launch line.
- `site/visual-brand.md`: the official visual brand (Montserrat, the blues, contrast, the logo) and the `brand-visual` check; canonical logo files in `brand/assets/` (`brand/README.md`).
- `campus-page/<state>.md`: per-state requirements (M3, waiting on the lifecycle decisions in `docs/findings-2026-09-15.md`).
