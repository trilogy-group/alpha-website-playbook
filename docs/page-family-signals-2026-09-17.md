## Notes and anomalies

- **No HubSpot forms embedded on the main conversion pages.** Only `/learn-more/` embeds a HubSpot form (`hbspt.forms.create` formId `d95ac89a-10ad-43c4-a90f-460cd0fd3179`, portal 40051392). `/admission/` has no form; `/admission-forms/` is a campus picker linking to `/application/?submission_campus=<slug>` (K-8, e.g. Austin, Atlanta) or `/application-fs/?submission_campus=<slug>` (most other campuses) or `alphahigh.school/application/`. The application page itself (`/apply/` → `/application-fs/?submission_campus=austin_k8`, page id 8352) loads `js.hsforms.net` but renders the HubSpot form client-side (no `formId` in the HTML) and swaps the H1 / admissions email via inline JS keyed on `submission_campus` — so H1 and contact email are not crawlable.
- **`/application-fs/` without a query string 301s to `/admission-forms/`**; with `?submission_campus=` it resolves to the application page (id 8352, title "Apply to Alpha School | Application Form", no canonical tag). `/high-school-application/` (id 8429) is the same JS-driven application template.
- **`/jb/` (page id 9619) renders the homepage's Elementor document (`data-elementor-id=3657`, popup 3713, same CTAs and map iframes)** — it is a homepage clone via template include, with its own two extra H1s ("Welcome, Johnathan Bi Fans"), giving 3 H1s. No meta description.
- **`/founders/` uses a different footer template (4107)** and has **no H1**; `/privacy-policy/` also has no H1. `/careers/` has no Elementor page document (theme/Gutenberg render, 48 main words) and no meta description — the page is essentially a stub linking out (footer/learn-more point careers to crossover.com/jobs).
- **Meta descriptions missing** on: blog post, /ai/ post, news post, video-resource single and archive, careers, /jb/, author archive. Hubs (`/blog/`, `/ai/`, `/news/`) have them.
- **`/resources/` (alpha_video_resource archive) is titled "Alpha Answers"** and the header nav item "Alpha Answers" points to `/resources/`; `/alpha-answers/` itself is a 404 (Elementor 404 template 3427). `/ai/` is titled "Artificial Intelligence" — the two "answers" concepts are split across `/ai/` (posts) and `/resources/` (video CPT).
- **Homepage/`/jb/` CTA `ATTEND AN EVENT IN YOUR CITY` → `/programs-events` (301 → `/upcoming-events/`)**; `/admission/` also links `/programs-events/`. Homepage `STAY IN-THE-KNOW…` button has `href="#"` (popup trigger). `Is Alpha a Fit?` → `match.app.alpha.school`. Locations map is an iframe from `map.app.alpha.school/map` plus a `maphub.net` embed.
- **Campus page (`/austin/`)** is the richest template: Google Maps embed iframe, Goldcast (events), Flipsnack, HubSpot meetings link (`go.alpha.school/meetings/alpha-school/austin`), `Place`/`PostalAddress`/`GeoCoordinates` schema, 1,383 main words. `/upcoming-events/` (4,138 words) carries `Event`/`Offer`/`Place`/`VirtualLocation` schema and Goldcast.
- **Blog, /ai/ posts and campus local-SEO posts share Elementor single-post template 4476**; news posts use single-post template **8919**; author archives use archive template **9123**. Video-resource singles have no Elementor document (theme template) but do emit `VideoObject` schema and a YouTube iframe.
- **`og:type` is `article` on almost every page** (including admission, locations, legal) — only `/` and `/resources/` are `website`, author is `profile`.
- Word counts: legal (6,378), events (4,138), FAQ (3,888) dominate; conversion pages are thin (`/admission-forms/` 129, `/learn-more/` 137, `/success/` 18, `/news/` hub 72, `/video-library/` 85 — the hubs are card grids with little indexable text).
