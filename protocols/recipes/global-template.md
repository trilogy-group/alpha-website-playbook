# Recipe: Global Templates, Navigation, Popups, and Scripts

This is staged human project work, not a routine scheduled-agent recipe.

## Inputs

- Dedicated APEX ticket
- Exact template, menu, plugin setting or code object
- All affected page families
- Owner and approval
- Current version and complete rollback artifact
- Performance, accessibility, consent, analytics and form impact
- Staging and production verification matrix

## Procedure

1. Resolve the target object and conditions.
2. Export or snapshot the complete current state.
3. Inventory dependent templates, CSS IDs, forms, scripts and pages.
4. Apply and test in staging.
5. Verify homepage, representative campus, another affected family, desktop, mobile, keyboard, forms, console and performance.
6. Prepare a production canary and rollback window.
7. Apply through the named platform owner.
8. Run the full shared-surface verification set and monitor the observation window.

Campus template changes preserve all n8n CSS IDs and update the template used to create new campus drafts.

## Stop conditions

Missing owner, unknown conditions, no rollback artifact, no staging parity, or unknown form and consent impact stops production.
